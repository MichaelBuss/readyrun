## Agent skills

### Issue tracker

Issues live as GitHub issues on MichaelBuss/readyrun. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles mapped 1:1 to tracker labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Release

Releases run through Changesets: behavior-changing PRs add a changeset; version fields, tags, and publish runs are never touched by hand. See `docs/agents/release.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
