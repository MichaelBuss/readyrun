The Plan discloses, best-effort and warning-only, any Frontier Ticket the Tracker reports unblocked whose blocker's merge marker the resolved base does not contain: for each such blocker it walks the base's first-parent history in the same `Ticket <id>:` grammar the Run's merges are written with, and run start, `run --preview`, and Doctor render the same warning in marker terms — the Tracker says unblocked; the base does not contain the marker — naming the landings that leave no marker (a squash, a family Delivery pull request, a hand merge that rewrote messages, a human-implemented blocker). It never refuses a Run, never changes what is picked, and is silent when the history cannot be read. Tracker Adapter answers widen with `leftFrontierBlockers`, the blocking relation's other half, and the shared contract covers it with no git (#70, ADR 0050).
