# Separate JSR package; GitHub and Linear adapters in v0

v0 is a generic loop with a Tracker seam, not a SpeechDeck-shaped CLI and not inlined bash in each consumer. It ships as its own repo and is published to JSR once ready. Both GitHub and Linear adapters ship in v0 because there are two real consumers today (SpeechDeck on GitHub, Trackunit on Linear). GitHub-only was rejected: the next copy-paste would be the Linear paragraph. Beads, a local issue file, and any other tracker are not implied by this decision.
