# Effort is optional, then CLI; the Worker Adapter maps the flag

A Worker’s effort is an optional config default (`low` | `medium` | `high` | `xhigh` | `max`). `--effort` overrides that default for the whole Run. The Worker Adapter maps the value to `--effort` (Claude and custom). Cursor has no such flag — effort is a model variant (`composer-2.5-fast`) — so the Cursor adapter does not map it, and Doctor fails rather than starting a Run that would ignore the setting. Encoding effort only in the model id was rejected because Claude’s effort is a separate flag; a required default was rejected because vendors already have their own; warn-and-continue was rejected because unused routing is a maybe, and a never-mapped flag is a lie. Ultracode is a Claude Code workflow setting, not an effort level.
