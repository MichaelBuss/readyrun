# The Plan is computed once; `run --preview` renders it read-only

A **Run** resolves everything it needs before its first side effect — **Doctor**'s verdict, the **Frontier** in stable pick order, the resolved base, the **Run Branch** it would collect onto, the resolved cap and where it came from, and the **Tickets** waiting off the **Frontier** with what blocks each. That resolution is the **Plan**, computed once with **Doctor** the single authority on validity and rendered read-only wherever a human looks. Run-start disclosure is the always-on rendering and now names the HEAD trap: when HEAD stands on a branch in the `readyrun/run-` namespace the default branch does not contain, it says so and points at `--base` from the default branch, because a Run with no `--base` there would cut a new **Run Branch** from a parked ref (#108). Membership in that namespace is what makes a checkout's branch count as a **Run Branch** for this detection (#148) — ReadyRun owns the prefix by convention, so the check reads the namespace rather than faithful per-Run ref state, which ReadyRun does not persist; the accepted consequences are a **Consumer** branch squatting in the namespace warning though no **Run** created it, and a **Run Branch** renamed out of the namespace escaping detection, both tolerable because the trap is a warning that never gates. `run --preview` is the opt-in rendering: it prints the **Plan** and ends with the exact equivalent `readyrun run …` command, so the flag surface is learned by reading rather than by failing a **Run** — the failure mode that motivated this. It exits before any mutation and skips the cwd-fidelity probe (ADR 0037), which is the **Run**'s to prove at start; the preview says the probe was not run. Waiting **Tickets** render with their blockers, which needs a small **Tracker Adapter** surface to hand over what the adapters already compute internally — both shipped adapters put `blockedBy` and `parent` on every **Ticket**; `frontier()` filters the waiting ones out (ADR 0016). Rejected: making **Doctor** itself print the **Plan** (its probe spawns the **Worker** once, so a cheap look through **Doctor** is neither cheap nor side-effect-free), and auto-corrected command lines on **Doctor** failures — where the remedy is a choice, a printed command would silently pick semantics the **Consumer** did not choose, so prose names the fix and the **Plan** carries the command.
