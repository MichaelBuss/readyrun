# A Worker's escape is detected, not assumed

The post-Worker checks are local to the Ticket — exit code, Worktree cleanliness, Branch tree versus base — so a Worker that worked somewhere else either passed invisibly or failed as "produced nothing on readyrun/40", accurate about the Branch and silent about where an 827-line commit actually went (the Consumer's checkout). Escape is now checked at two moments. Before a **Run** starts, **Doctor** proves cwd fidelity: it cuts a throwaway **Worktree** in a temp directory, spawns the real **Worker** through the Adapter's own spawn on a trivial prompt, captures the output, and asserts the Worker's commands executed in that directory — the one honest way to catch a CLI that re-roots linked worktrees, since such an Adapter spawns and auth-probes perfectly (this is Doctor-owned and distinct from the Adapter's optional auth `probe()` of ADR 0023, and it is the first Doctor check that makes a real model call, so it captures output and runs under a timeout — neither existed for spawned processes before). During the **Run**, the postcheck snapshots repo-global state before each spawn — the **Consumer** checkout's HEAD and `status --porcelain` (excluding `.readyrun/`, which the Run itself creates), and a `git for-each-ref` digest (excluding the **Ticket**'s own **Branch**, whose advance is success, not escape) — and diffs after the Worker exits. Any change outside the Ticket's **Worktree** and **Branch** is a worker-stage hard stop whose detail names what moved ("the Consumer's checkout advanced from X to Y on <branch>"), taking precedence over "produced nothing", which keeps meaning what it says. This also separates the two outcomes the old message conflated: did nothing, and did the work elsewhere. The snapshot is taken per spawn, not per Run: serial v0 makes that race-free (ADR 0007) and later concurrency a knob, not a rewrite. Ticket-local checks alone were rejected because they cannot see across the worktree boundary; auto-reverting an escape was rejected because the Run's job is to stop honestly and keep the scene intact (ADR 0029), not to perform surgery on the Consumer's checkout.
