# A Launcher assembles a Run on a TTY; the terminal during the Run stays the Run's

ADR 0019 allowed Clack on **Init** only and sent every run wizard away; ADR 0025 refused surfaces no **Consumer** has asked for. Both premises moved: the product's only human user is its maintainer, who hates the terminal, and a standing preference of that user is not speculation — #108's usage-evidence gate is answered by want, not statistics (the one real failed **Run** — an interdependency discovered by failing rather than reading — is supporting evidence for the **Plan** renderings, not for a menu). So bare `readyrun` opens a Clack **Launcher** on a TTY and prints usage off one; with no config found, it offers **Init** first. ADR 0019's strongest objection, that **Doctor** would have to explain two surfaces, is met by the **Plan** (ADR 0039): the **Launcher** collects answers, hands them to the same code path the flags feed, renders the **Plan**, and never holds a rule of its own — everything it collects is flag-expressible, the `run`/`doctor` flag paths are unchanged, and an unattended **Run** still never prompts, because the **Launcher** exists only at the moment a human types the command. On confirm the **Launcher** exits its own UI and the **Run**'s ADR 0035 renderer owns the terminal; there is no chrome around a live **Run**. Phased: v1 assembles a **Run** — cap (suggested from the **Plan**'s **Frontier** size, never below a list root's floor), **Permissions**, model, **Effort**, and a **Run Branch** base picker that answers #108's HEAD-state logic (HEAD is a **Run Branch** the default branch does not contain → point at `--base` from the default branch; HEAD is the default branch with an unmerged **Run Branch** → offer the picker; HEAD already contains the newest **Run Branch** → a fresh **Run**, no continue offered). v2 adds picking **Tickets** from the **Tracker** as a tree with hierarchy and blocked status, which grows the **Tracker Adapter** surface. The **Run Branch** picker lists **Run Branches**, never **Worktrees** (ADR 0029).
